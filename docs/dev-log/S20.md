**Status:** landed by agents. Spec review passed. Logic review passed with one minor. Gate after simplify: 762 passed, 5 skipped. The human demo on the deployed app is still outstanding.

## Summary

Dropped photos on New video now go through Files, Media and Providers instead of the in-memory stand-ins. The bucket can delete an object. An object over 25 MiB is deleted on complete. Labelling uses the real probe, thumbnail and label call, with a mocked transport in the gate. Opening New video without the passphrase returns 401 with a Basic challenge. The 12 test shoots stay outside the repo.

## Decisions

- `files.delete_object` removes a key. A missing key is not an error. Photoshoots uses it only when the stored object is over 25 MiB (26214400 bytes).
- Stills are sized with `media.probe`. ffprobe returns width and height for a JPEG.
- The plan-step tests still intercept Photoshoots. S21 removes that stand-in.
- The screen refuses a file over 25 MiB before upload, so the oversized-after-upload test writes 26214401 bytes into the fake bucket itself.
- Pages that presign a thumbnail start the fake bucket. That setup is shared from `tests/conftest.py`.
