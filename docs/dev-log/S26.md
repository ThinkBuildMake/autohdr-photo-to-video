## What was built

1. **Real seams for import and run.** `evals import` calls Photoshoots, `evals run` calls Jobs to create and submit. Before submitting, the run waits for the shot plan. A failed or timed-out plan is written to the sheet and that job is skipped. One shared deadline (`--timeout-min`, default 480) covers the wait. On timeout the sheet is written for what finished and the exit is non-zero. Each run gets its own folder (UTC microseconds plus 4 hex characters, created without `exist_ok`), so two runs in one second cannot collide. Duplicate shoot labels pick the newest ready shoot and print a warning. The sheet has a row for every attempt, including attempts with no clip, plus the round, the clip key, the style text on plan rows and the reference link on reproduction rows. `relink_sheet` writes a new sheet with fresh links, because clip links expire in an hour and review takes about two. `ev2` refuses a style with no reference video.
2. **Report and CLI.** Videos are keyed by job id, so several sheets (EV-1 plus each preset's EV-2) do not merge. Each video shows visibly AI shots, rooms changed, movement and transition matches, worst cut error, job time and status. A cut check with no measurement on a plain cut counts as a VR-2 failure. Each style shows reproductions that look like the reference, plans where the text was followed, and movement and transition matches over delivered attempts only. The catch rate counts reviewer-failed attempts the check flagged, ignoring attempts with no clip. An `## Unreviewed` list names delivered attempts with a blank mark, and the report exits 2. The README results section is replaced mechanically and only when every delivered shot is reviewed and the videos were delivered. Everything else in the README is kept, and a second fill gives the same file. New commands: `report --sheet A --sheet B --readme README.md`, `links --sheet S` and `all --folder F --yes`. Without `--yes`, `all` prints what it would spend (12 plus 2 per preset real jobs) and exits 1 without creating jobs.
3. **Metrics, drafts and stub check.** `python -m app.metrics --sheet SHEET` limits every panel to the sheet's job ids, so panel 2 shows the median submit-to-playable over the EV-1 jobs. Without it nothing changes. `drafts.py` reads the real photoshoot status (404 for an unknown shoot, 409 for one still awaiting upload). `scripts/check_stubs.py` is an AST scan like the media check. The gate fails if non-stub app code imports a module named `stubs` or contains the string `stub-media`.
4. **Full-gate evals over real modules.** `tests/evals/test_wire.py` runs import and run over the real Photoshoots and Jobs on the mocked bucket and mocked provider answers, including a stopped job. The timeout test is now deterministic.
5. **README and ignore rules.** The results section is honest: it says no paid run is recorded and gives the one command for the real run. The signed-link reports under `evals/` are ignored by git so they cannot be committed.

## Decisions

- **Paid criteria are proven with mocks only.** Real runs spend money and need the owner's go-ahead. The build makes the real run one command and the README stays honest until a real, fully reviewed sheet exists.
- **Stub modules stay as test fixtures.** `app/jobs/stubs.py`, `app/library/stubs.py` and `app/photoshoots/stubs.py` are used by about 20 tests and by each other. "No stub left" means no non-stub app code imports one and no route answers `stub-media`. S27 moves the files.
- **Panel 2 stays across all jobs by default.** `--sheet` narrows it to the EV-1 jobs.
- **A run is not resumable, but it is not lost.** An interrupted run (Ctrl-C or an error) writes its sheet from the current job state, one row per created job, prints the path and re-raises. `links` and `report` work from that sheet. Starting again still makes a new set of jobs.
- **A missing job is a row note.** The run goes on and the sheet says "the job is missing"; "not found" in the report appears only when the job row is really missing.

## Bugs found

- **A flaky timeout test.** `test_jobs_that_do_not_finish_in_time_still_get_a_sheet_and_a_failing_exit` failed once and passed on rerun, because the wait raced the planner thread. Subtask 4 made it deterministic.
- **Review of subtasks 1 to 3 found no blocking issues,** only the minors listed under Open.

## Review round 1 fixes

- `.gitignore` now ignores `/evals/` only. The bare `evals/` also hid `app/evals/` and `tests/evals/` from `git add`.
- A run writes its sheet in a `finally`: after Ctrl-C, an error while waiting, or a failure while building rows (that job keeps a bare row with its job id and a note). The run folder is made before the first job is created.
- Every sheet row has a `providers` column (`real` or `fake`, from FAKE_PROVIDERS at run time). The README fill is refused unless every row is `real`, at least 12 EV-1 videos were delivered, every shoot in `shoots.json` has an EV-1 video, and at least one EV-2 reproduction is present. Older sheets without the column are refused.
- `all` counts EV-1 jobs from the folder's subfolders, keeps running later suites after a timeout (exit 1) and prints each sheet path as it is done. A sheet missing a mark column gives a clear error.
