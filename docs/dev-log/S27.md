## What was built

1. **Last app stubs moved to tests.** `app/library/stubs.py`, `app/photoshoots/stubs.py` and `app/jobs/stubs.py` became one `tests/support/stub_data.py`, and the 15 test files that used them were re-pointed. S26's `scripts/check_stubs.py` and `tests/gate/test_no_stubs.py` were extended, not duplicated, so any `stubs.py` or stubs import under `app/` outside `app/evals` fails the gate.
2. **Live clip check and offline-copy tool.** `tests/providers/video/test_live_clip.py` asks the production video model for one 4 s clip and checks the length. It is skipped unless `OPENROUTER_LIVE=1` and a key are set, so the gate never runs it. `scripts/demo_video.py fetch` downloads a job's video through `/api/jobs/{id}/video` with the passphrase from `~/.autohdr-demo-passphrase` (or `DEMO_PASSPHRASE`). `verify` needs a video stream, an audio stream and at least 20 s.
3. **Demo script.** `docs/DEMO.md` has sections for before (redeploy with `railway up`, `/healthz`), the live clip check, the live flow in order (preset, upload, plan, Make my video, play, editor re-export, comparison beside its reference), the pre-made demo job and its offline copy, the fallback rule, the freeze, and the wireframe screen pass. `tests/docs/test_demo_doc.py` checks the headings and order, that every AC2 stage is named, that referenced repo paths exist and that the passphrase is absent.

## Decisions

- **Frozen means no source and no auto-deploy.** The service has no connected repo, so deploys only come from `railway up`. The freeze is shown by reading the service config and pushing a commit that produces no deployment. If a source is ever connected, it is disconnected or auto-deploy turned off.
- **No theme changes.** The wireframe colours and font already match `app/web/static`. The screen pass is a human walk; defects go to the follow-ups list, not into this story.
- **Fetch never prints secrets.** The passphrase lives only in the auth tuple, and the signed download link is never printed. A test checks both are absent from output.
- **Offline copy is checked for audio.** The existing probe reads only the first video stream, so `verify` adds an audio-stream check.
